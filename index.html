Sin datos guardados en este navegador
⚠
El guardado permanente no está disponible en este navegador para este archivo. Esto pasa normalmente cuando el HTML se abre con doble clic (dirección que empieza con file://). La herramienta va a funcionar con normalidad durante esta sesión (puedes cargar, calcular y exportar), pero los datos se perderán si cierras o recargas la página. Para que el guardado permanente funcione, abre este mismo archivo desde un servidor local o una intranet (dirección que empieza con http:// o https://) en vez de hacer doble clic sobre él.
