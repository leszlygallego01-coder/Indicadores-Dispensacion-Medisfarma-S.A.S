No se pudo conectar con Firebase Cloud Firestore. Esto puede ocurrir si no hay conexión a internet o si el navegador bloquea el acceso. La herramienta va a funcionar con normalidad (puedes cargar, calcular y exportar), y los datos se guardarán localmente en este navegador usando localStorage. Sin embargo, los datos no se guardarán en la nube ni se sincronizarán con otros dispositivos. Verifica tu conexión a internet y recarga la página para restablecer la sincronización.
